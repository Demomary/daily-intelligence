# Daily Intelligence

每日中文技术与产业情报简报归档。

## 关注范围

1. **技术突破与开源项目**：AI 与非 AI 技术；重点关注 C、LuaJIT、DPDK、网络协议仿真及工程工具。
2. **AI 公司与产业竞争**：模型、Agent、AI 编程、基础设施与商业化。
3. **工业自动化与实际应用**：PLC、工业通信、工业 AI、设备诊断、数字孪生及真实部署。
4. **中国大陆及国际重大时事**：关注具有实质影响的政策、科技、外交与社会事件。
5. **经济、商业与社会热点**：重要产业变化、企业动态与宏观经济。
6. **具身智能与机器人**：VLA、世界模型、操作与运动控制、触觉、仿真训练、Sim-to-Real 和量产落地。
7. **AI 眼镜与第一视角智能设备**：连续视觉记录、环境理解、多模态助手、端侧算力、功耗、隐私与新交互入口。

## 简报原则

- 每期优先选取最多 5 条高价值信息，按重要性与新颖度排序，不为凑数而收录。
- 标注事件发生时间与信息来源的原始发布日期，避免把旧闻包装成新消息。
- 优先引用官方公告、论文、代码仓库及 Release、独立评测和可靠媒体。
- 区分厂商自述、独立验证结果与尚未证实的信息；对性能数字说明测试范围和限制。
- 不只罗列新闻，还说明技术变化、实际意义、成熟度和需要继续验证的问题。
